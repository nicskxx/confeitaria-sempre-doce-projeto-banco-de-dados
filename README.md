# projeto banco de dados
**Nome do projeto:** Site da confeitaria sempre doce
**Equipe de desenvolvimento:** Nicolas de Campos Barboza
## 1. Visão geral do sistema(Escopo)
A **Confeitaria Sempre Doce** deseja criar um site para vender seus doces que são feitos com muito amor e carinho mantendo a tradição de familia.
## 2. Requisitos Funcionais (RF)
**RN01**: O sistema deve gerenciar o cadastro de seus clientes, as informações uteis que foram levantadas são:

 - Nome Completo
 - Telefone
 - Email
 - Endereço

**RN02**: O sistema deve permitir que o cliente envie uma mensagem com as informações do seu pedido, a mensagem sera envia via formulário do sistema, com as seguintes informações:

 - Nome
 - Email
 - Telefone
 - Endereço
 - Texto da mensagem
